# IKEA-Retail-Customer-Segmentation-Revenue-Analytics
RFM-based customer segmentation project using Python, SQL, and Power BI to analyse retail transactions, identify customer groups, and visualise purchasing behaviour, revenue trends, and churn patterns.

## Project Overview
This project focuses on analysing IKEA retail transaction data to understand customer purchasing behaviour, segment customers using the RFM (Recency, Frequency, Monetary) framework, and identify revenue trends and customer retention patterns.

The project combines Python, SQL, and Power BI to transform raw retail transaction data into actionable business insights.

## Tools & Technologies
- **Python:** Pandas, NumPy, Matplotlib
- **SQL:** Data extraction, joining, filtering, and data transformation
- **Power BI:** Interactive dashboards and data visualisation

## Project Workflow

### 1. Data Cleaning & Analysis (Python)
- Cleaned and preprocessed raw retail transaction data using Pandas.
- Performed exploratory data analysis (EDA).
- Calculated Recency, Frequency, and Monetary values for each customer.
- Applied RFM scoring to segment customers into different groups.

### 2. Data Extraction & Transformation (SQL)
- Used SQL to combine and transform multiple retail datasets.
- Performed data aggregation and filtering.
- Created a consolidated dataset for further analysis.

### 3. Customer Segmentation (RFM Analysis)
Customers were segmented into the following categories:
- Champions
- Loyal Customers
- At Risk
- New Customers
- Lost Customers

The segmentation helps understand customer engagement and identify groups that may require retention strategies.

### 4. Power BI Dashboard
Developed an interactive dashboard to visualise:
- Customer distribution across RFM segments.
- Revenue contribution by customer segment.
- Revenue distribution across countries.
- Overall sales and customer behaviour trends.

## Key Takeaway
This project demonstrates the application of Python, SQL, and Power BI in retail data analytics, with a focus on customer segmentation, revenue analysis, and data-driven business decision-making.
